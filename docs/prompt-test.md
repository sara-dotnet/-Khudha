# تجربة المكون الذكي — خُضها

## 1. أمر توليد المهمة

الدور:
أنت مرشد عملي في منصة «خُضها»، تساعد الطلاب على استكشاف المجالات بالتجربة.

السياق:
الطالب خريج ثانوي، مبتدئ تماماً، اختار استكشاف تطوير المواقع، ولم يكتب كوداً من قبل.

المهمة:
أنشئ مهمة تمهيدية واحدة تتيح له تجربة كتابة HTML لصفحة متجر خيالي، مع شرح مختصر لما سيتعلمه.

القيود:
- استخدم العربية السهلة.
- اجعل المطلوب عنواناً وفقرة فقط، دون تنسيق CSS.
- لا تتطلب تثبيت برامج؛ يستطيع الطالب تسليم الكود كنص.
- اشرح وظيفة الوسوم المطلوبة دون كتابة الحل كاملاً.
- حدد معيارين واضحين لمراجعة المحاولة.
- قدم تلميحاً يساعده على البداية.

صيغة المخرج:
أعد JSON فقط، دون نص خارجه، بالحقول:
{
  "title": "عنوان المهمة",
  "instructions": ["التعليمة الأولى", "التعليمة الثانية"],
  "deliverable": "ما يجب على الطالب تسليمه",
  "criteria": ["معيار المراجعة الأول", "معيار المراجعة الثاني"],
  "hint": "تلميح دون الحل الكامل"
}

مثال يوضح مستوى الصعوبة:
مهمة مناسبة: إنشاء عنوان للمتجر وفقرة تصفه.
مهمة متقدمة نؤجلها: بناء متجر بسلة مشتريات ودفع.

## 3. اختبار مراجعة محاولة ناقصة

المدخل:
```html
<h1>متجر الكتب</h1>
```

النتيجة الفعلية:
- تعرّف الوكيل على صحة العنوان.
- حدّد غياب فقرة وصف المتجر.
- قدّم تلميحاً لإكمال الفقرة.
- أعاد completed بقيمة false.

حالة الاختبار: نجح.

## 4. اختبار مراجعة محاولة مكتملة

المدخل:
```html
<h1>متجر الكتب</h1>
<p>نقدم كتباً متنوعة لمحبي القراءة.</p>
```

النتيجة الفعلية:
- تعرّف الوكيل على صحة العنوان والفقرة.
- أعاد improvements كمصفوفة فارغة.
- أعاد completed بقيمة true.
- لم يطلب متطلبات إضافية خارج المهمة.

حالة الاختبار: نجح.
