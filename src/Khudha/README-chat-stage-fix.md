# فصل شات الاستكشاف حسب المرحلة

كان الطلب السابق يضم تعليمات للثانوي والجامعي معاً، ويرسل تفاصيل المسارات
حتى في رحلة الثانوي. قد يدفع ذلك الوكيل إلى إنهاء رده بدعوة غير مناسبة لاختيار مسار.

التعديل:

- يمرر الخادم رمز المرحلة الفعلي إلى الوكيل، بدلاً من الاعتماد على وصف المرحلة وحده.
- تضبط تعليمات النظام دوراً واحداً مطابقاً للمرحلة الحالية.
- للثانوي: تعريف التخصص من الصفر، وشرح المصطلحات والأمثلة ودرس التجربة التمهيدية.
  لا يرسل سياق الاختيار أو المسار المحدد أو خطط مهام المسارات الجامعية.
- للجامعي: المقارنة بين المسارين المتاحين وتوضيح طبيعة كل منهما والمساعدة على الاختيار.
- تسترجع مراجع التجربة التمهيدية فقط لشات الثانوي، بينما تسترجع مراجع المسارات للجامعي.
- الرسائل السابقة تبقى محفوظة؛ تعاد تجربة السؤال للحصول على رد جديد بالتعليمات المحدثة.

الحزمة تحتوي KhudhaAi.cs وKhudhaFlow.cs وKhudhaSelfTests.cs وهذا الدليل.
لا تحتاج تغيير ملفات الواجهة أو قاعدة البيانات أو مفاتيح API.

## التركيب على جهاز C

أوقف الموقع بـ Ctrl+C في تيرمنال التشغيل. ثم:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\khudha-chat-stage-fix.zip" -DestinationPath "C:\Users\lutfi\-khudha\src\Khudha" -Force -ErrorAction Stop
dotnet run --project "C:\Users\lutfi\-khudha\src\Khudha\Khudha.csproj" -- --self-test
if ($LASTEXITCODE -eq 0) {
    dotnet run --project "C:\Users\lutfi\-khudha\src\Khudha\Khudha.csproj" --urls "http://localhost:5050"
}
```

أضيفت للفحص الداخلي حالات للتخصصين تتأكد من عدم وجود قائمة اختيار مسارات
في سياق الثانوي، ومن وجود خطته التمهيدية فقط، ومن بقاء مساري الجامعي وخطتيهما.
الفحص الداخلي لا يستدعي SQL أو Gemini. لم يُشغل بناء .NET هنا؛ يُشغل بالأمر أعلاه على جهاز الفريق.

## اختبار الرد الحي

في رحلة الثانوي أعد السؤال «هل هو صعب؟». يجب أن يشرح صعوبة تعلم التخصص
وكيفية البدء التدريجي، دون عرض اختيار مسار. في رحلة الجامعي اسأل «ما الفرق
بين المسارين؟» وتأكد من استمرار المقارنة المناسبة. لا تعتمد على الرسالة القديمة لاختبار التعديل.

بعد تأكيد الرد، يمكن رفع الملفات الأربعة من جهاز C إلى فرع develop ثم سحبها
على الجهاز الآخر وإعادة تشغيل خادمه.
