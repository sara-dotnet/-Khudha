# تحديث تصميم خُضها

تصميم مدمج من ملف `preview.html` المرسل، ومبني على إصلاحات المشروع التي رُفعت في التحديث `871c6bc`.

## ما تتضمنه الحزمة

- `wwwroot/index.html`: الرئيسية، النموذج، التعريف، الدروس، مساحة المهام والمراجعة.
- `wwwroot/styles.css`: الهوية البيضاء والبنفسجية، البطاقات، تنسيق الشاشات الواسعة والجوال.
- `wwwroot/app.js`: الربط الحالي بالخادم، مع تنقل الصفحة، قائمة الجوال، اختيار التخصص من البطاقات، وشريط التقدم الحقيقي.
- `wwwroot/assets/khudha/`: أربع رسومات SVG محلية مقتبسة من التصميم المرسل.

تستمر الجلسات والاختيارات والمهام وإجابات الطالب والمراجعة عبر API المشروع الحالي. يستخدم الشات والمراجعة اتصال Gemini الموجود في المشروع. لا يتضمن هذا التحديث منطق المراجعة المحلي أو النسب المحسوبة بعدد الكلمات من المعاينة المرسلة.

لا توجد مكتبات جديدة، أو خطوط وصور تحتاج تحميلًا خارجيًا، أو تعديلات على ملفات C# أو قاعدة البيانات أو إعدادات الاتصال. التخصصان الحاليان ومساراتهما هما المحتوى المتاح. يظل شريط النموذج مفتوح الصياغة: «اختر التخصص أو المسار اللي ودّك تستكشفه».

## التركيب على جهاز C

من تيرمنال الأوامر، نفّذ كل أمر منفصلًا. إذا ظهر خطأ في النسخ الاحتياطي، عالج الخطأ قبل فك التحديث.

حفظ نسخة من الواجهة الحالية في التنزيلات:

```powershell
Compress-Archive -Path "C:\Users\lutfi\-khudha\src\Khudha\wwwroot" -DestinationPath "$env:USERPROFILE\Downloads\khudha-ui-backup-$(Get-Date -Format yyyyMMdd-HHmmss).zip" -ErrorAction Stop
```

تركيب الواجهة الجديدة:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\khudha-purple-design-update.zip" -DestinationPath "C:\Users\lutfi\-khudha\src\Khudha" -Force -ErrorAction Stop
```

إذا كان الموقع يعمل، افتح `http://localhost:5050` واضغط `Ctrl + F5`. ملفات الواجهة تُقرأ من `wwwroot`؛ لا يحتاج هذا التحديث بناء C# جديدًا.

إذا كان الموقع متوقفًا، شغّله:

```powershell
dotnet run --project "C:\Users\lutfi\-khudha\src\Khudha\Khudha.csproj" --urls "http://localhost:5050"
```

## التركيب على جهاز D

بعد رفع التحديث من جهاز C إلى GitHub، يمكن لجهاز D سحب التحديث المعتاد. إذا كان التركيب مباشرة من الملف المضغوط، غيّر مسار التطبيق في أمرَي النسخ الاحتياطي وفك الضغط إلى:

```text
D:\khudha\-khudha\-khudha\src\Khudha
```

عنوان التشغيل على جهاز D هو `http://localhost:5174`.

## فحص الواجهة بعد التركيب

1. ظهور التصميم الأبيض والبنفسجي، والرسم التوضيحي والبطاقات.
2. فتح قائمة التخصصات يعرض علوم الحاسب وإدارة الأعمال. الكتابة تتيح البحث، وتغيير المرحلة يمسح الاختيار السابق.
3. بطاقة تخصص على الرئيسية تنقلك للنموذج. إذا لم تختر المرحلة، يحتفظ باختيار البطاقة حتى تحدد مرحلتك؛ ولا يبدأ جلسة قبل ضغط «ابدأ الاستكشاف».
4. الثانوي يرى تعريف التخصص ودرسه، والجامعي يرى المسارات ثم درس المسار المختار.
5. الدرس والمثال وخطة المهام والشات متاحة قبل أول مهمة.
6. المراجعة والتقدم مرتبطان بنتيجة الوكيل؛ ينتهي المسار عند إكمال المهام الثلاث.
7. العودة للرئيسية ومتابعة التجربة وتحديث الصفحة تحفظ الإجابات والنتيجة المعتمدة.
8. قائمة التنقل تعمل على الجوال، ويمكن إغلاقها بزر القائمة أو مفتاح Escape.

## التحقق الذي أُجري

نجحت اختبارات JavaScript الفعلية باستخدام محاكاة DOM وAPI للرحلات الست، والحفظ والمراجعة، وتعارض التبويبات، واستعادة الإجابة المعتمدة، ومنع نقل الإجابة النصية السابقة لمهمة جديدة، والتنقل وبطاقات التخصصات وشريط التقدم. تحققنا من سلامة تركيب HTML، وبقاء عناصر الربط السابقة، ووجود ملفات الرسومات وروابط الأقسام. طابقت بصمات ملفات الخادم والمحتوى النسخة السابقة.

لم يُجر تشغيل متصفح فعلي أو SQL Server أو Gemini في بيئة إعداد الحزمة. الاختبار البصري والاتصال الفعلي يتمان على جهاز تشغيل المشروع بعد التركيب؛ اختبارات المحاكاة ليست بديلًا عن هذا الفحص.
