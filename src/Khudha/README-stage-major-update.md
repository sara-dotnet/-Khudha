# تحديث المرحلة والتخصص

## السلوك الجديد

- خيارات المرحلة: «خريج ثانوي» و«طالب أو خريج جامعي».
- قبل اختيار المرحلة تكون خانة التخصص فارغة ومعطلة.
- للخريج الثانوي يظهر «حدد التخصص»، وللجامعي يظهر «حدد تخصصك».
- الاقتراحات تظهر عند فتح الخانة، وتتصفى بالكتابة؛ ويمكن كتابة تخصص غير موجود فيها.
- السهمان للتنقل، وEnter للاختيار، وEscape للإغلاق. اختيار التخصص لا يرسل النموذج تلقائياً.
- تغيير المرحلة يفرغ التخصص. الاسم المطلوب من حرفين إلى 120 حرفاً.
- يُحفظ التخصص مع الجلسة ويظهر في التجربة وعند استرجاعها.
- الجلسات السابقة التي لا تحتوي تخصصاً تظل قابلة للاسترجاع دون اختراع تخصص لها.

التخصص الدراسي يختلف عن مجال التجربة العملية. هذا التحديث يجمع التخصص ويحفظه
ويضيفه لسياق الوكيل، بينما التجربة المجهزة حالياً تبقى تطوير المواقع كما يوضح
النص في صفحة البداية. اقتراح تخصص في القائمة لا يعني أن تجربة لذلك التخصص
قد بُنيت. توسيع التجارب يُنفذ كتعديل مستقل.

## التركيب على النسخة السابقة

1. أوقف تشغيل الموقع بواسطة Ctrl+C في تيرمنال تشغيله.
2. فك khudha-stage-major-update.zip داخل مجلد src/Khudha، مع استبدال الملفات الخمسة المعدلة.
3. شغل المشروع مجدداً، ثم افتح «الرئيسية» وحدّث الصفحة إذا كانت الواجهة مخزنة مؤقتاً.

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\khudha-stage-major-update.zip" -DestinationPath "C:\Users\lutfi\-khudha\src\Khudha" -Force
dotnet run --project "C:\Users\lutfi\-khudha\src\Khudha" --urls "http://localhost:5174"
```

لا يتطلب التحديث ملف SQL جديداً؛ يستخدم حقل DiscoveryAnswersJson الموجود في
جدول Sessions لتخزين major. لا يغير إعدادات الاتصال أو مفتاح API أو نموذج Gemini.

## التحقق

أُنجز فحص صيغة JavaScript، ومعرّفات عناصر الواجهة، وخيارات المرحلة. كما أُنجز
اختبار سلوك البرنامج باستخدام محاكاة DOM وAPI: القيم الفارغة، البحث العربي،
الاختيار بالكيبورد، التخصص الحر، التحقق من المدخلات، محتوى طلب إنشاء الجلسة،
عرض التخصص المسترجع، واستمرار عرض تقدم الجلسات السابقة.

هذه ليست اختبارات متصفح فعلي أو تكامل SQL Server. بناء .NET والتحقق من الحفظ
الفعلي يُنفذان على جهاز الفريق بعد تركيب التحديث.

اختبار يدوي مقترح: اختر خريج ثانوي وتأكد أن الخانة فارغة؛ اختر تخصصاً من
الاقتراحات؛ غيّر المرحلة إلى الجامعي وتأكد أنها تفرغ؛ اكتب تخصصاً غير مقترح
وابدأ التجربة؛ ثم حدث الصفحة وتحقق من ظهوره في بيانات التجربة.
